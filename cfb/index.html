How it works

  1. In WhatsApp, open the draft group → ⋮ or group info → Export chat → Without media. Save the .txt file.
  2. Go to Import WhatsApp Draft, paste the export (or upload the file), review the picks, and download draft.csv.
  3. Replace data/cfb/draft.csv in this repo with your file (or edit that CSV by hand if the parser misses a pick).
  4. Refresh team records periodically: 
    python3 tools/update_cfb_records.py --season 2026
  5. Check Standings — default scoring is 1 point per win (0.5 per tie).
